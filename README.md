# Benessere Network - contenuti

Ecosistema contenuti di Benessere Network / Etna Wellness: dall'articolo del blog al video YouTube,
alla copertina, all'articolo aggiornato e al post Facebook, in automatico.

- `.claude/skills/video-bn/SKILL.md` - la catena completa e le regole (stile, voce, CTA, pubblicazione, routine)
- `Video/BenessereNetwork/PROCEDURA.md` - procedura del montaggio e stile approvato
- `Video/BenessereNetwork/montaggio.py` - voce Gemini TTS, clip Pexels, montaggio ffmpeg, controllo qualita'
- `Video/BenessereNetwork/carica_youtube.py` - caricamento YouTube (anche programmato), miniatura, primo commento
- `Video/BenessereNetwork/progetti/` - un progetto per contenuto (copione, metadati, miniatura, esito YouTube)

Routine (ora italiana): 06:47 bozza articolo, 09:17 video e copertina + mail "Contenuto pronto",
17:41 pubblicazione articolo, YouTube e Facebook + mail "Pubblicato". Ritmo deciso dal calendario Airtable.
